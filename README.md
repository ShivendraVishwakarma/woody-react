# Woody React

A refined interior design studio website built with React, Vite, React Router, and custom CSS.

## Run Locally

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` starts the Vite dev server.
- `npm run build` creates a production build in `dist`.
- `npm run lint` runs Oxlint.
- `npm run preview` serves the production build locally.

## Project Structure

- `src/components` contains shared and homepage sections.
- `src/pages` contains routed pages for home, projects, project details, studio, and contact.
- `src/assets/images` contains the project and studio imagery.
